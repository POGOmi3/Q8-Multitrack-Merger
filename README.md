# Q8-Multitrack-Merger

Zoom Q8 で録画した分割ファイルを、DaVinci Resolve Studio でそのまま編集できる
「マルチトラック MOV（1本化ファイル）」に自動で変換する Windows 向けツールです。
個人利用専用です。

## 何をするツールか

Q8 は長い録画を 4GB ごとに分割して保存します。1回の録画で次の3系統ができます。

- 映像つきの分割 `.MOV` ファイル（複数）
- 内蔵マイクで録った分割 `.WAV` ファイル（複数）
- ライン入力で録った分割 `.WAV` ファイル（複数）

このツールは、各系統を FFmpeg で劣化なしに（再エンコードせず）つなぎ合わせたうえで、
元の MOV に入っている音声は使わず、次の構成で1本の `.mov` にまとめます。

- 映像：元の MOV の映像
- 音声1（A1）：内蔵マイクの WAV
- 音声2（A2）：ライン録音の WAV

映像も音声も再圧縮しないため、画質・音質は元のままです。

## 使い方

※アプリ本体（`main.py` など）は現在準備中です。完成後にここへ手順を追記します。

1. ビルド済みのフォルダをダウンロードする（下記「ビルド方法」参照）
2. `Q8-Multitrack-Merger.exe` を起動する
3. Q8 の録画フォルダを選ぶ
4. 出力先とファイル名を確認して実行する

FFmpeg は .exe と同じフォルダに同梱されるため、別途インストールする必要はありません。

## 開発環境

- Python 3.10 以上
- PySide6
- FFmpeg（外部コマンドとして呼び出し。配布時は同梱）

```
main.py            … 画面（GUI）の入り口
core/
  __init__.py
  merger.py        … ファイルの自動分類・並び替え・FFmpeg 実行
requirements.txt   … 必要なライブラリの一覧
```

## ビルド方法（.exe の作り方）

GitHub Actions で自動ビルドします。手元の PC でビルドする必要はありません。

1. このリポジトリの「Actions」タブから `Build Windows EXE` を選び、手動実行する
   （または `v*` という名前のタグを付けると自動で実行されます）
2. 実行が終わると、Artifacts に `Q8-Multitrack-Merger-Windows` が出ます
3. ダウンロードして解凍すると、フォルダの中に `Q8-Multitrack-Merger.exe` と
   `ffmpeg.exe` などが入っています。フォルダごと使ってください

ビルド方式はフォルダ形式（PyInstaller の onedir）です。.exe 単体ではなく、
フォルダのまま移動・保管してください。

## 注意

- 元の録画ファイルは変更しません。出力は別のファイルとして書き出します。
- 対応 OS は Windows 10 / 11 です。
